# Camera

Universal Android camera application foundation.

- App name: **Camera**
- Application ID: `com.sahidcode404.camera`
- Minimum Android version: **API 23 (Android 6.0)**
- Camera control plane: **Camera2**, with optional CameraX preview adapter
- Primary still format: **multi-frame RAW -> merged DNG**
- Development distribution: **GitHub Actions + development OTA**

This repository is being bootstrapped from scratch with the universality, startup, camera-ownership, AUX discovery, preview, RAW-processing, and OTA principles established in `sahid-code404/CamX`, without vendor/model hardcoding.
